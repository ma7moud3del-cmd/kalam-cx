Lean Six Sigma

Cut the waste first, then automate

Every project runs DMAIC: Define, Measure, Analyze, Improve, Control. Steps that add no value are removed before anything is automated, and every result is checked against a measured baseline.

D Define · M Measure · A Analyze · I Improve · C Control. Green = done, yellow = in progress now. Measure is still open for most projects because the baseline is set in Discovery.
